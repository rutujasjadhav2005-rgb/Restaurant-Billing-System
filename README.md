# 🍽️ Restaurant Billing System Using Python

## 📌 Project Description

The Restaurant Billing System is a menu-driven Python project that helps manage restaurant orders and calculate customer bills. It allows users to view menu items, add orders, calculate subtotals, apply 5% GST, and display the final bill.

This project demonstrates the use of Python classes, objects, lists, dictionaries, loops, conditional statements, and functions.

## 🎯 Project Objectives

* Display restaurant menu items and their prices.
* Add food items to customer orders.
* Calculate the subtotal of all ordered items.
* Calculate 5% GST on the subtotal.
* Generate the final bill, including GST.
* Provide a simple, interactive billing system.

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Platform:** Jupyter Notebook
* **Concepts:** Object-Oriented Programming (OOP), Classes, Objects, Lists, Dictionaries, Loops, Conditional Statements, and Functions

## ✨ Features

1. **Display Menu:** View available food items and their prices.
2. **Add Order:** Select a menu item and enter its quantity.
3. **Display Order:** View ordered items, prices, quantities, and totals.
4. **Calculate Subtotal:** Calculate the total cost before GST.
5. **Calculate GST:** Apply 5% GST to the subtotal.
6. **Calculate Final Bill:** Calculate the total amount, including GST.
7. **Exit:** Close the billing system.

## 🧮 Billing Formula

* **Item Total** = Item Price × Quantity
* **Subtotal** = Sum of all item totals
* **GST** = Subtotal × 5%
* **Final Bill** = Subtotal + GST
